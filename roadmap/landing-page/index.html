Debt that has a name and a date on it

Most teams already write down their debt, in comments, and then lose it. Fragmo is meant to make that visible to the people who plan the work.

Owner and age tracking

Every item gets an owner and an age in days from git history, so nothing sits in a file for three years with nobody's name on it.

Weekly digests per person

Each developer gets one short message with their own overdue and soon-due items. You get the team roll-up, in Slack or email.

PR checks

A check on the pull request flags new debt that has no owner or no deadline, before it merges instead of after it ages.

Coming next: other debt sources, such as lint suppressions, skipped tests and outdated dependencies. Tell us which one you want first in the waitlist form below.

Built by the maintainer of todonotifier, the open-source CLI

The scanning engine is not a promise. todonotifier is an MIT-licensed Python tool you can run on your own repositories today:

  • finds TODO-style comments and ignores strings and docstrings
  • works out the owner and age of each item from git blame
  • runs as a command, a pre-commit hook or a GitHub Action, and can post to Slack, Teams or a webhook
Source on GitHub Read the docs
